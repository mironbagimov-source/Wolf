# Character body models

The four `*_body.glb` files are avatars from the **100Avatars** project by
**Polygonal Mind** (https://github.com/PolygonalMind/100Avatars), released as
open source / CC0-style free assets ("a free gift to the world" — see the
project README). Files are unmodified VRM binaries renamed to .glb:

- survivor_body.glb — 100Avatars_058_Shiro
- cannibal_body.glb — 100Avatars_030_Bloody
- leader_body.glb   — 100Avatars_031_Devil
- killer_body.glb   — 100Avatars_050_Samuela

Idle/Walk/Run animations are retargeted at bake time from soldier.glb
(three.js example asset, MIT) by tools/retarget.gd.
