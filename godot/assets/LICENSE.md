# Ассеты

## cast.glb — модели игры

Четыре тела: `guest`, `trickster`, `witch`, `roger`. Слеплены скриптом
`../tools/blender_cast.py` из примитивов и жёстко привязаны к костям (каждая
деталь целиком к одной кости). Отсюда угловатость — это осознанный лоу-поли:
такой силуэт читается в тумане формой, а не текстурой.

Пересобрать после правки скрипта:

```bash
blender --background --python godot/tools/blender_cast.py
```

Все четыре меша сидят на одном скелете и лежат в одном файле, поэтому анимации
не дублируются вчетверо. При спавне игра оставляет нужный меш, остальные
удаляет (см. `Actor._build_model`).

## soldier.glb — донор скелета

Риг персонажа Soldier (Vanguard) из примеров three.js —
`examples/models/gltf/Soldier.glb`, репозиторий
[mrdoob/three.js](https://github.com/mrdoob/three.js), лицензия MIT.

В игре больше не появляется: из него берутся только скелет и анимации
(`Idle`, `Walk`, `Run`, `TPose`), на которые насаживаются свои тела. Нужен
скрипту сборки — удалять нельзя, иначе `cast.glb` будет не из чего пересобрать.

Когда дойдут руки до собственного скелета и анимаций — менять здесь.
