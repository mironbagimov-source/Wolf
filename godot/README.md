# Wolf — Godot-версия (основная)

Полный порт игры на Godot 4.3+: три стороны (Жертва / Кибер-псих / Наёмник),
ближний бой, метательные ножи, стелс с приседом, захваты на имплант-стол,
добивания с exec-камерой, выбор персонажа, ночной неоновый квартал.

## Запуск

1. Установи **Godot 4.3 или новее** (godotengine.org, бесплатно, ~100 МБ).
2. В Godot: **Import** → выбери файл `godot/project.godot` из этого репозитория.
3. Нажми **F5** (Play). Всё.

Никаких пакетов и настроек не нужно: уровень, материалы и UI строятся кодом
при запуске.

## Фотореализм

Проект настроен на рендерер **Forward+** — на компьютере с нормальной
видеокартой автоматически включаются: объёмный туман, SSR-отражения неона
в лужах на мокром асфальте, SSAO, блум, ACES-тонмаппинг, мягкие тени.
(Скриншоты из среды разработки сняты в режиме Compatibility — программный
рендер без части эффектов; у тебя картинка будет богаче.)

Крутилки: `scripts/level.gd` → `build_environment()` (туман/блум/экспозиция)
и `_ground()` (лужи: Gradient в roughness-текстуре).

## Модели персонажей

Сейчас все стороны используют риггованную модель **Soldier.glb** (MIT, из
примеров three.js; уже в репо) с анимациями Idle/Walk/Run, фракционной
подсветкой и кибер-обвесом: глаза-импланты/клинок у психов, шипы у Альфы,
неоновый визор у наёмников, рюкзак у жертв.

**Подключить свои (фотореал) модели** — без правки кода: положи `.glb` в
`godot/assets/characters/` с именем:

| Файл | Кому |
|---|---|
| `survivor.glb` | Жертвы |
| `cannibal.glb` | Кибер-психи |
| `leader.glb` | Альфа |
| `killer.glb` | Наёмники |

Слот подхватит их автоматически (см. `char_body.gd → setup_visual`).
Где брать легально: Mixamo (бесплатные риггованные персонажи), Sketchfab с
лицензией CC0/CC-BY, Asset Library. Ассеты из самой Cyberpunk 2077 — нельзя,
это собственность CDPR.

## Управление

Мышь — осмотр · WASD — движение · Shift — бег · **C — присед** ·
ЛКМ — атака/захват · ПКМ — блок (наёмник) / захват (псих) · **Q — нож** ·
**F — добивание** (Мясник, Клинок) / фонарь (жертва) · E — взаимодействие ·
ESC — освободить курсор.

## Headless-проверка (для CI/агентов)

Игра самотестируется без дисплея: переменные окружения `WOLF_TEST`
(`menu` / `merc` / `psycho` / `victim` / `exec`) и `WOLF_SHOT` (путь PNG).
Пример:

```bash
WOLF_TEST=exec WOLF_SHOT=/tmp/shot.png \
  godot --path godot --rendering-method gl_compatibility
```
