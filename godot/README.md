# Рейвенсторп — Паразит (Godot 4)

Хоррор-шутер от первого лица в духе **F.E.A.R.**: отряд из трёх наёмников —
**Джейкоб** (вы), **Мойра** и **Томас** — прибывает в норвежское поселение
Рейвенсторп, где бесследно исчезли двадцать женщин и десять мужчин. След ведёт
в закрытый исследовательский центр, где паразит превращает людей в
гигантских пауков.

Это отдельная, «настоящая» версия игры на Godot 4 (рядом с браузерным
прототипом на Three.js в `../web-prototype/`, где та же боевая петля).

## Как запустить

1. Поставь **Godot 4.2** или новее (стандартный редактор, не .NET-версия —
   весь код на GDScript).
2. **Godot → Import** → выбери файл `godot/project.godot` из этого репозитория.
3. Нажми **▶ (Play, F5)**. Главная сцена — `scenes/Main.tscn`.

Проект **полностью текстовый**: ни одного бинарного ассета. Весь мир, персонажи,
пауки, HUD и звук строятся кодом при запуске, поэтому в git лежат только
`.gd`/`.tscn`/`project.godot`, а Godot досоздаёт свой кэш (`.godot/`) локально.

## Управление

| | |
|---|---|
| **WASD** | движение |
| **Мышь** | осмотр |
| **ЛКМ** | огонь (авто, удерживай) |
| **ПКМ** | рефлексы — замедление времени (slow-mo), фирменная фишка F.E.A.R. |
| **R** | перезарядка |
| **Shift** | бег |
| **F** | фонарь на оружии |
| **ESC** | освободить/захватить курсор |

Рефлексы замедляют **весь мир**, но темп стрельбы остаётся реальным — это чистое
преимущество: успеваешь целиться и уклоняться. Шкала тратится при удержании и
восстанавливается сама.

## Сюжет (скриптовая сцена)

Режиссёр (`Main.gd`) ведёт игрока по битам:

1. **Прибытие.** Отряд у ворот центра. Задача — проникнуть внутрь.
2. **Первый контакт.** У дверей выходят **три гигантских паука** — первые враги.
3. **Выживший.** После зачистки из дверей выходит **больная женщина**. Говорит,
   что здесь ставили опыты, что паразит уже во всех них.
4. **Перелом.** Она **бросается на Томаса**. Появляется подсказка — **стреляй**.
   Пуля убивает её — и **из её тела рождается паук** (кровавый «взрыв», визг).
5. **Осада.** Центр оживает: три волны тварей. Отбейся — и прорывайся к точке
   эвакуации на юге.

Мойра и Томас — не декорации: идут в строю, стреляют по паукам, могут пасть.
Концовка зависит от того, кто дошёл до эвакуации.

## Архитектура

```
godot/
  project.godot            конфиг (главная сцена = scenes/Main.tscn)
  icon.svg                 иконка
  scenes/Main.tscn         пустой корень со скриптом Main.gd
  scripts/
    Main.gd    (GameMain)  мир, режиссёр сцены, спавн, урон, волны, победа/поражение
    Player.gd  (Player)    от первого лица: движение, взгляд, стрельба (ray/sphere),
                           отдача, перезарядка, рефлексы (Engine.time_scale), фонарь
    Spider.gd  (Spider)    процедурный паук: тело + 8 анимированных лап + глаза,
                           автомат: spawn→chase→windup→leap→recover→dead, рождение
    Ally.gd    (Ally)      Мойра/Томас: строй, стрельба по паукам, ранение
    Woman.gd   (Woman)     носитель: выход, реплики, бросок на Томаса, рождение паука
    Hud.gd     (Hud)       весь UI кодом: меню, здоровье/рефлексы/патроны, задача,
                           статус отряда, субтитры, подсказки, баннеры, концовки
    Sfx.gd     (Sfx)       синтез звука из PCM (AudioStreamWAV): выстрелы, стрёкот,
                           сердцебиение, «рождение», ветер — без ассетов
```

Осознанные решения для устойчивости и чистого git:
- **Без физического движка.** Движение — ручная проверка по AABB-коллайдерам,
  попадания — ray/sphere. Никаких `CollisionShape`, слоёв и утечек физики.
- **Всё кодом.** Ноды и материалы создаются в `_ready`/`setup`, поэтому нет
  хрупких путей в сценах и `.import`-пайплайна.
- **Модель врага процедурная.** Пауки и люди собраны из примитивов — не нужен
  импорт glTF/FBX, ничего не «ломается на загрузке».
