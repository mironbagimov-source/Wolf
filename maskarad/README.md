# Маскарад

Асимметричный социальный хоррор на Godot 4.3, **от первого лица**. Ночной
город: клуб, верфь или усадьба — карта выбирается перед матчем. Среди толпы
ходят вампиры и личи, у людей нет оружия: только чеснок, ноги, нычки и
умение понять, кто перед тобой.

Прототип играется целиком: выбираешь любого из семи персонажей, остальных
ведут боты, ночь заканчивается победой одной из сторон.

## Как запустить

**Просто поиграть.** Взять готовую сборку — распаковать и запустить
`Maskarad.exe`. Godot ставить не нужно, это один самодостаточный файл.

**Открыть исходники.**

1. Скачать **Godot 4.3** (или новее) — обычный редактор, без .NET:
   https://godotengine.org/download
2. Godot → **Import** → выбрать `maskarad/project.godot` → **Import & Edit**.
3. **F5** (или ▶ в правом верхнем углу).

Первый импорт занимает секунд десять — движок сам создаёт папку `.godot`,
её в репозитории нет и быть не должно.

## Собрать сборку самому

В редакторе: **Project → Export**. Пресеты `Windows Desktop` и `Linux` уже
лежат в `export_presets.cfg`, оба собирают один файл со вшитым содержимым
(`embed_pck`). Один раз понадобится докачать шаблоны экспорта — Godot
предложит сам (**Editor → Manage Export Templates**).

Из командной строки, без редактора:

```bash
godot --headless --path maskarad --export-release "Windows Desktop" build/windows/Maskarad.exe
godot --headless --path maskarad --export-release "Linux" build/linux/Maskarad.x86_64
```

### Почему сборка не 242 МБ

Модели пришли с текстурами 4096×4096 на каждого персонажа — это 140 МБ
пикселей, которых на ночной улице не видно. Готовые сборки собраны с
уменьшенными до 512:

```bash
python3 tools/shrink_textures.py         # 4096 -> 512
rm -rf maskarad/.godot
godot --headless --path maskarad --editor --quit
```

Скрипт правит только PNG, распакованные импортёром; сами FBX не трогает,
так что полное разрешение всегда возвращается удалением PNG и `.godot`.
Итог: 4096 → 242 МБ, 1024 → 146 МБ, 512 → 103 МБ.

## Управление

| | |
|---|---|
| `W` `A` `S` `D` | идти, `Shift` — бежать, `Пробел` — прыжок |
| мышь | повернуться: влево — влево, вправо — вправо, от себя — вверх, на себя — вниз |
| `ЛКМ` | удар (только у нечисти) |
| `ПКМ` (средняя, `Alt`, `C`) | **оглянуться**, не разворачиваясь: тело стоит, голова свободна |
| `E` | действие: спрятаться в нычку / заговорить / добить лежащего / держать — пить кровь |
| `Shift`+`E` | вампир: **пригласить на танец**; нечисть над схваченным или лежачим: **взять на плечо**; лич над лежачим при психозе от 80: **казнь** |
| `F1` | качество картинки: высокое / среднее / низкое |
| `Shift`+`ЛКМ` | лич: **вселить духа** в того, на кого смотришь |
| `ЛКМ` вплотную | вампир: **захват** — не замах, а рывок и зубы в шею |
| `ЛКМ` из нычки | вампир: **удар из засады** — валит с ног сразу |
| `M` | карта города во весь экран |
| `Q` | люди — чеснок; нечисть — **«мне плохо, помогите»** |
| `V` | нечисть: **погасить прожектор** рядом |
| `G` | нечисть: **швырнуть что-нибудь** — свидетели уйдут смотреть туда |
| `R` | зажать рану — кровь останавливается, но ты стоишь |
| `F` | способность: чужой облик у вампира, берсерк у лича |
| `Tab` | кто ещё жив |
| `Esc` | отпустить мышь |

## Правила ночи

**Стороны.** Люди и нечисть. **Таймера нет** — ночь не кончается сама.
Люди побеждают, когда **зажгут все прожекторы**: свет везде, прятаться
негде. Нечисть побеждает, когда людей не осталось. Гости бала в счёт победы
не идут — они массовка, укрытие и еда.

Раньше здесь тикал обратный отсчёт, и людям хватало дожить: можно было
забиться в нычку и ждать рассвета. Теперь работа есть у обеих сторон, и матч
кончается только когда одна её сделала. Прожектор можно и **погасить** — это
умеет нечисть, и это единственный способ отыграть назад уже сделанное.

**Злодей в матче ровно один, и его выбирает игрок.** Взял монстра — он и
есть тот самый. Взял человека — злодея выбирает жребий, и людям заранее
неизвестно, кто пришёл: вампир, которого надо вычислить, или лич, от
которого надо бежать. Двое монстров разом били по обеим сторонам: люди
метались между двумя разными угрозами и не успевали разобраться ни в одной,
а игроку-монстру второй монстр поднимал шум и распугивал зал, в котором тот
работал тихо.

**Повреждения по частям тела.** Здоровье — не одна полоска. Удар в голову
бьёт вдвое сильнее и оглушает, по ноге — отнимает скорость и оставляет
хромоту, по руке — силу собственного удара. Раны кровоточат: кровь утекает
из здоровья и капает на пол, а по каплям за тобой приходят. `R` зажимает
рану, но пока держишь — стоишь на месте.

**Люди — Хельга, Джей, Кьяра.** Атаковать не умеют вообще. Отличаются
показателями и одним приёмом на каждого: Хельгу не берёт ужас лича, Джея
почти не слышно, Кьяра видит мерцание чужого лица на вампире и носит лишний
чеснок.

**Вампиры — Мойра (серп) и Люциус (шпага).** Играют в социальный стелс:
внешне это такой же человек в толпе. Копят голод — **заговаривают** жертву,
та подходит, и её выпивают. Кормиться при свидетелях опасно: кто увидел, тот
знает. При полной шкале голода вампир **принимает облик выпитого**.

А если надеть лицо **Марии**, диджея клуба, открывается второй путь: звать
не «на пару слов», а **в гримёрку**. Туда человек идёт сам, через полклуба,
и там нет свидетелей вообще. Ради этого лица и стоит охотиться.

**Личи — Лара (гарпунное ружьё) и Карл (топор и нож).** Никакого маскарада.
Копят психоз убийствами — при полной шкале уходят в берсерк: быстрее,
больнее, и вокруг них люди замедляются. **Медленнее любого человека** —
догнать по прямой не могут в принципе, и вся их охота построена на том,
чтобы отрезать, зажать в тупике или снять гарпуном.

## Оружие: у каждого своё правило

| | |
|---|---|
| **Серп** Мойры | часто и неглубоко, но рвёт: жертва истекает кровью и оставляет след, по которому её найдут |
| **Шпага** Люциуса | не машет вовсе. Открывается окно, по полосе ходит метка — попал в момент, и клинок проходит насквозь мимо любой живучести. Промахнулся — открылся сам |
| **Гарпунное ружьё** Лары | выстрел не убивает, а сажает на линь и тянет обратно. Добивают уже вплотную, и Ларе на это идти через весь зал |
| **Топор и нож** Карла | самый тяжёлый удар в игре и самый долгий замах. Это окно — единственное, что есть у жертвы |

**Люди держат удар.** Гости и люди не умирают с одного попадания: сначала
их сбивают с ног, и они ползут. Пока лежит — его **добивают**, полторы
секунды на виду у всех, кто рядом. Не добили вовремя — встал. Из-за этого
убийство перестало быть мгновенным и стало заметным: главный риск для
нечисти теперь не промах, а свидетель. Шпага — единственное исключение:
точный укол проходит мимо любой живучести.

## Приёмы вампира

Уводить в комнату — только один способ, и самый заметный. Есть ещё пять.

**Танец** (`Shift`+`E`). Не ты идёшь к жертве — она встаёт напротив сама и
смотрит на тебя, а не по сторонам. Когда музыка кончается, она стоит
вплотную и повёрнутая, и это полторы секунды, в которые можно начать пить.
Расплата в том, что танцуют на виду: на людном танцполе это самоубийство.

**Засада из нычки** (`ЛКМ`, сидя в укрытии). В нычке вампира не видно, и
первый удар оттуда валит с ног сразу — жертва не успевает ни обернуться, ни
закричать. Работает один раз: после удара из укрытия приходится выйти.
Поэтому засада ставится не там, где удобно стоять, а там, где кто-то ходит.

**«Мне плохо, помогите»** (`Q`). Самый дешёвый зов: на помощь идут не
думая, а подошедший наклоняется — и нагнувшийся не смотрит по сторонам.
Одному и тому же человеку второй раз не поверят.

**Погасить свет** (`V`). На свету не кормятся: увидят. В темноте свидетелем
становится только тот, кто стоит вплотную. Заодно откатывает работу людей.

**Швырнуть что-нибудь** (`G`). Приманка наоборот: гости идут смотреть на
звон стекла ТУДА, а не сюда. Уводит свидетелей, а не подводит жертву.

Все приманки на одном откате — по очереди, а не залпом.

**Кормление — это захват.** Жертва подтягивается вплотную и разворачивается
к вампиру; хватают сразу, а пьют потом. По ходу кормления голова
запрокидывается всё сильнее, колени подгибаются, руки перестают держаться —
к концу она не стоит, а висит в руках.

## Казнь — приём лича вблизи (аналог мементо мори из DBD)

`Shift`+`E` над **лежачим**, если психоз набран на восемьдесят. Лич поднимает
человека за горло, держит на вытянутой руке — тот бьётся ногами, цепляется за
чужое запястье, пока может, — заносит оружие и убивает своим способом.

Отличие от обычного добивания не в цифрах, и это важно. Добивание — способ
закончить начатое: полторы секунды работы. Казнь — способ **отказаться от
осторожности**:

* три секунды лич стоит на месте и ничем не может ответить;
* слышно вдвое дальше, чем любой другой шум в клубе;
* тратится весь накопленный психоз разом — на сотне был бы берсерк;
* **казнённого не поднять гулем.** Тело после неё ни на что не годится.

То есть за неё платят своими же будущими руками. Ею не «добивают
эффективнее» — ею ставят точку, когда важнее, чтобы зал это видел.

## Одержимость — дистанционный приём лича

`Shift`+`ЛКМ` по человеку в пределах двадцати метров, за половину шкалы
психоза. Лич не идёт сам: он вселяет в человека злого духа, и дальше человек
работает на него, не сходя с места.

Исход лич не выбирает. Либо одержимый **накладывает на себя руки** — тихо,
без свидетелей, и со стороны это несчастный случай, в котором лича никто не
заподозрит. Либо **бросается на тех, кто рядом**, — и тогда группа дерётся
сама с собой, а лич в это время просто идёт мимо. Второй исход шумный, но он
разваливает группу, а против группы у лича шансов нет.

**Вскрытый вампир не может драться вообще.** Увидели, как он пьёт, или
сорвали чужое лицо чесноком — и всё его оружие это ноги и тени. Вампир
силён ровно до того мгновения, пока его считают гостем.

**Палево.** Лич может устроить резню — но каждый, кто это увидел, запоминает
лицо и до утра обходит его стороной. После первой поножовщины лич работает
по пустому городу: толпа, в которой можно было кого-то поймать, разбежалась.
С вампиром то же самое, если его застали за кормлением.

**Чеснок.** Единственный инструмент людей. Попал по вампиру — с того слетает
чужое лицо, он светится на весь зал и не может прятаться. Попал по человеку
или гостю — толпа оборачивается на бросавшего, оглушение и потеря здоровья.
Личу чеснок безразличен, и это тоже ответ: если отскочило — перед тобой не
вампир.

**Смерть вампира.** Вампир не оставляет тела: он расходится роем, как
дочери Димитреску в RE8 — фигура теряет связность и обращается в тучу,
которая ещё секунду держит форму человека. Это не только вид: труп — улика,
по которой люди понимают, что среди них кто-то есть, и у вампира такой улики
нет. Его смерть можно вообще не заметить.

**Обращение.** Человека, пойманного вампиром, с вероятностью 50 на 50 либо
убивают, либо поднимают низшим вампиром. Лич поднимает гулем. Обращённый
остаётся в матче и играет уже за нечисть — в том числе если это был игрок.

## Карты

Карта выбирается перед матчем, и это разные ночи, а не куски одного города.
Отличается не только планировка — на каждой у гостей своё занятие, и от него
зависит, где толпа, где тихо и как к человеку подойти.

| | |
|---|---|
| **Ночной клуб «Маскарад»** | 24 гостя. Один огромный зал: две сцены, танцпол, бар во всю стену, балкон над залом, за кулисами гримёрки и подсобки, у входа гардероб со шкафами. Самое людное место: вампиру есть где стоять, но и свидетелей больше всего |
| **Верфь и склады** | 16 человек ночной смены. Работают у верстаков, курят на причале, дежурят. Простор и длинные линии — ночь Лары |
| **Усадьба** | 20 человек. Прислуга разносит, гости беседуют и танцуют, кто-то спит в спальне. Анфилада комнат: увести проще всего, понять кто ушёл — труднее всего |

**Занятие — это не украшение.** Занятый гость стоит на месте, значит к нему
можно подойти; и он хуже смотрит по сторонам, значит подойти можно вплотную.
Танцующий не видит почти ничего, курящий у входа видит всех входящих,
охранник замечает всё, спящий не проснётся и не закричит. Испугавшись, гость
бросает работу — но, отбегав своё, возвращается на место.

## Клуб: одна локация вместо города из комнат

Раньше здесь был город из восьми районов — клуб, бар, деревня, башня, склад,
отель, парковка, улицы, — и это была ошибка. Двадцать четыре гостя на восемь
районов дают по три человека на район: ни толпы, ни давки, ни социального
стелса, ради которого всё затевалось. Половину ночи обе стороны бежали по
пустым улицам между районами.

Теперь это **один зал**, огромный и трёхъярусный, и весь народ в нём. Всё,
что было отдельными районами, стоит внутри — не через улицу, а за дверью:

| | |
|---|---|
| **Главная сцена** | на неё смотрит весь зал — значит, все стоят спиной ко всему остальному |
| **Вторая сцена** | подиум сбоку: своя музыка, своя кучка людей, свой свет |
| **Танцпол** | самая густая толпа. Танцующий не видит почти ничего |
| **Бар** | стойка во всю западную стену; за стойку можно сесть |
| **VIP-балкон** | второй ярус над залом. Сверху видно всё, снизу балкон почти не виден |
| **Гримёрки** | четыре комнаты за сценой, в каждую одна дверь. Туда идут добровольно за лицом звезды |
| **Подсобки** | склад со стеллажами, щитовая, холодильник — три глухих помещения |
| **Гардероб** | два ряда **шкафов** у входа, и в каждый можно влезть |
| **Туалеты** | кабинки, куда уходят по одному |
| **Загрузка** | тёмный двор за кулисами: ни гостя, ни окна |

Ходить между ними — секунды, а не полминуты. Из-за этого работает и охота, и
бегство: жертву уводят из толпы за десять шагов, и за те же десять шагов
возвращаются в толпу, пока никто не хватился.

**Нычки.** Шкафы гардероба и за кулисами, проход за барной стойкой, кабинки
туалетов, щели между стеллажами склада, тень за колонками сцены, диваны
балкона. Стоя в нычке, человек перестаёт быть виден
дальше пары метров. Против лича, от которого по прямой не убежать на длинной
дистанции, это единственный работающий ход — и боты им пользуются: убегая,
человек ищет укрытие, но не то, что лежит за спиной у преследователя.

**Карта** (`M`) показывает обеим сторонам разное, и в этом весь смысл. Человек
видит планировку и нычки. Нечисть поверх того же плана видит **размеченные
места для нападения**: приватные комнаты и тёмные углы, где нет свидетелей.
Охота планируется по карте до того, как жертву туда заведут.

## Что здесь моё, а не из концепции

Эти вещи в исходной концепции не оговаривались, я их добавил, чтобы матч
складывался в игру. Всё вынесено в таблицы и снимается за минуту.

- **Жаровни.** Четыре штуки, каждая зажжённая приближает рассвет на 40 секунд
  и выжигает круг, где вампир не носит чужое лицо. Без активной цели людям
  оставалось только бегать по кругу семь минут.
- **Гости.** Двадцать два человека в городе, пять разных лиц: диджей Мария,
  косплеерша Медея, скуф Толян, реконструкторша Василиса и пьяный Гоша.
  Социальный стелс не существует без толпы: вампиру негде стоять, а зажатому
  человеку не за кем спрятаться.
- **Условия победы и длина ночи** — семь минут, выживает хоть один.
- **Один вампир и один лич** в матче по умолчанию: против них нужны разные
  повадки, и людям приходится решать, к какой угрозе готовиться.

## Чего пока нет

**Сетевой игры.** Матч одиночный: игрок за любого персонажа, остальные — боты.
Архитектура к сети готова (актёр не знает, кто им управляет — игрок или мозг-
бот, они пишут в одни и те же поля), но `MultiplayerSpawner` и синхронизация
не написаны.

Ещё нет звука и разговоров между гостями.

**Готовых анимаций.** Модели пришли с Mixamo без клипов — одна T-поза. Шаг,
удар, укус, захват, хромота и падение считаются кодом, покостно
(`scripts/rig_anim.gd`). Выглядит это как анимация «на троечку», но выглядит.
Если положишь рядом клипы `Idle`/`Walking`/`Running` с Mixamo — их можно
будет включить вместо расчёта.

**Мышь поворачивает персонажа**, и между ними ничего не стоит: влево —
влево, вправо — вправо, от себя — вверх, на себя — вниз. Была попытка
сделать тоньше — корпус доворачивался за головой с задержкой, чтобы
«оглянуться на бегу» получалось само собой, без кнопки. На бумаге красиво,
в руках отвратительно: ведёшь мышью, а персонаж стоит и смотрит вбок,
потом идёт не туда, куда ты смотришь. Управление важнее приёма, задержку
убрал.

Оглянуться, не разворачиваясь, можно на `ПКМ`: пока держишь, плечи стоят,
голова свободна в пределах шеи, отпустил — тело догнало взгляд. Со стороны
это видно: rig скручивает шею и верх спины, и по вывернутой голове понятно,
что человек смотрит не туда, куда идёт.

Захват мыши восстанавливается сам, и движение мыши поворачивает камеру даже
когда захвата нет. Это не перестраховка: свёрнутое окно, увод фокуса или
окно, открывшееся неактивным, оставляли игру без управления навсегда — и
выглядело это ровно как «камера не крутится мышью», без единой подсказки,
что произошло. Единственное исключение — курсор, отпущенный игроком по
`Esc`: его не отбирают, и про это состояние теперь написано на экране.
Элементы HUD переведены в `MOUSE_FILTER_IGNORE`: нажимать в нём нечего, а
любая панель под курсором съедала движение мыши до игрока.

Удар разложен на замах, проводку и возврат: длина замаха берётся из оружия,
поэтому топор Карла заносится полсекунды, а шпага Люциуса — вчетверо
быстрее, и по чужому замаху видно, успеваешь ты отойти или нет. Укус
играется с обеих сторон: вампир наваливается и уводит голову к шее, у
жертвы голова отклоняется, спина выгибается, колени подгибаются.

**Готовых моделей оружия.** Серп, шпага, гарпунное ружьё, топор и нож
собраны геометрией (`scripts/weapon_mesh.gd`) и висят на кости кисти. Клинок
наводится в мировых осях каждый кадр, а не подвешен под фиксированным углом
к кости: у кисти Mixamo +Y идёт вдоль пальцев, а её X и Z у каждой модели
свои, и любой угол «на глаз» давал оружие торчком вбок.

Персонаж без своей модели собирается из примитивов (`scripts/body.gd`) — так
что игра не ломается, если какой-то файл убрать.

## Внешний вид

Свет: цветные приборы на ферме над танцполом, прожекторы сцены, неон вдоль
стойки и перил, объёмный туман в лучах, экранные отражения в полу, SSAO и
SSIL, плёночная тональная компрессия со свечением. Объёмный туман и отражения
работают только в **Forward+** (режим по умолчанию); в Compatibility они
просто не рисуются, и это единственное, что теряется на слабой машине.

Ночь тёмная, но не слепая. Прошлая была именно слепой: в зале не читались ни
стены, ни люди. Общий свет подняли и развели по цвету — низ холодный, блики
тёплые, — чтобы силуэт отделялся от фона даже там, куда не достаёт ни один
прибор.

Толпа разная в лицо: наряд, оттенок кожи, волосы и рост гостя считаются от
его зерна — иначе зал выглядит как склад манекенов, и вампиру негде теряться.

### Мимика

Лицевых костей в моделях нет вовсе — скелет Mixamo кончается на `Head`, — и
блендшейпов тоже нет. Поэтому выражение сделано накладкой поверх готовой
головы (`face_rig.gd`), и главное её правило — **не спорить с моделью**: у
всех персонажей глаза уже нарисованы, и рисовать поверх них вторые нельзя.
Своих глазных яблок в накладке нет. Есть только то, чего у нарисованного лица
быть не может: **веки** (моргание, прищур, полуприкрытый взгляд мертвеца),
**брови** (подняты домиком — испуг, сведены к переносице — злоба), **рот** —
и только раскрытый, тёмным овалом, потому что закрытый у модели свой, — и
**клыки** у вампира.

Всё это включается только когда работает. Спокойное лицо — лицо модели.

Куда именно класть накладку, пришлось разводить на два источника, потому что
ни один по отдельности не годится. **По высоте** — доли от кости головы: она
сидит в основании черепа, а это анатомически почти ровно уровень глаз, и доли
от неё переносятся с модели на модель. Габарит меша по высоте не годится: к
кости головы привязаны волосы и капюшон, и «голова» Хельги оказывается вдвое
выше настоящей. **По глубине** — наоборот, от измеренной ширины головы: доли
от кости здесь не работают, у Мойры лицо глубже, и накладка, севшая точно у
Хельги, у неё оказалась внутри черепа.

Числа выверены снимками головы крупным планом с раскрашенной накладкой и
линейкой сбоку (`--facecheck --mood=debug`), а не на глаз.

### Руки

В моделях сорок пальцевых костей, и до сих пор не двигалась ни одна: кулак
был отлит вместе с предплечьем. Теперь пальцы сжимаются на рукояти оружия,
смыкаются на жертве в захвате, растопыриваются и дрожат, пока жертва
вырывается, разжимаются, когда та перестаёт, и **никогда не стоят на месте**:
в покое они мелко подрабатывают в такт дыханию и шагу. Разница между «рука» и
«протез» — вот эта дрожь в полтора градуса.

## Звук

Ни одного звукового файла в проекте нет: всё синтезируется в память при
запуске (`sfx.gd`). Шум с огибающей даёт шаг, удар и звон; тон с падающей
высотой — бочку и сердце; пила с вибрато — крик. Причина не в экономии, а в
том, что готовые сэмплы пришлось бы откуда-то взять, с лицензией и на сотню
мегабайт в репозитории.

Зачем это вообще: вся механика игры построена на шуме — у каждого есть
`noise`, боты слышат драку, приём «швырнуть» целиком звуковой, — а игрок из
этого не слышал ничего и играл в стелс без основного канала.

**Музыка клуба глушит шум, и это правило карты.** У главной сцены не слышно
ни шагов, ни крика, в подсобке слышно всё. Один и тот же множитель идёт и в
громкость для игрока, и в радиус тревоги для ботов (`Game.raise_alarm`), так
что громкие и тихие места одинаковы для обеих сторон. Танцпол стал местом,
где можно подойти вплотную — и где к тебе подойдут.

**Сердце** стучит тем чаще, чем ближе монстр, и работает через стену: увидеть
за стеной нельзя, а почувствовать можно. У нечисти сердца нет.

## Переноска

Захват упирался в кормление на месте: где схватил, там и пил, на глазах у
зала. Уносить было нельзя, и все приватные комнаты работали только как
приманка — увести человека можно было исключительно уговорами.

Теперь схваченного или лежачего берут на плечо и несут. Цена: вдвое медленнее,
драться нельзя (обе руки заняты), и ношу видно всем. Жертва вырывается по
шкале — но чем больше из неё выпито, тем слабее сопротивление, поэтому выгодно
отпить пару глотков и нести потом. Бот-вампир пользуется этим сам: схватив на
людях, он ищет ближайшее место без свидетелей и уносит туда.

## Двери

До них все проёмы были пустыми, и погоня сводилась к бегу по прямой: лич
медленнее, но не устаёт, и рано или поздно догоняет в тупике.

Человек закрывает дверь за собой — и она заперта. Нечисть её только выбивает:
две секунды и грохот на весь этаж. Это и секунды для человека, и метка на
карте для всех остальных.

Одна тонкость в устройстве: **навмеш печётся один раз**, в начале матча. Если
бы дверь стояла с коллизией, в навмеше на её месте была бы дыра, и боты не
ходили бы в проём никогда — ни через открытый, ни через закрытый. Поэтому в
момент выпечки коллизии нет: она появляется только когда дверь закрывают.
Бот-лич опознаёт закрытую дверь не по навмешу, а по тому, что стоит на месте,
хотя идти ему есть куда.

## Как людям вычислить вампира

Увидеть кормление — больше не единственный способ.

* **Опросить гостя** (`E`). Гости запоминают, кто прошёл мимо них в сторону
  закрытых комнат, и называют имя и место. Теперь вампиру опасно просто
  мелькать у гримёрок.
* **Номерки гардероба** (`E` у стойки). Пальто сдали все, кто вошёл, а в зале
  остались не все. Разница — счёт погибших. Тело вампир уносит, номерок нет.
* **Голод**. Раньше голод был только бонусом, и вампиру ничто не мешало
  пересидеть ночь в углу. Теперь с 88 клыки не убираются: вблизи это видит
  любой гость, Кьяра — через зал.

**Упавшего поднимают.** Сбитый встаёт сам через девять секунд, товарищ
поднимает за три — единственная причина, по которой троим людям выгодно
держаться вместе. Боты это тоже умеют, но не лезут под нос убийце.

## Катсцены

Три, и каждая делает работу. **Вступление** — облёт зала: клуб большой, и без
него первые полминуты уходят на то, чтобы понять, где сцена и куда ведут
двери. **Казнь** — камера отходит и смотрит со стороны: приём, ради которого
лич отдаёт весь психоз, обязан быть виден целиком, а от первого лица видно
только чужую спину. **Итог** — отъезд от того, кто остался стоять. Любая
пропускается любой клавишей.

## Почему подвисало за человека — и что с этим сделано

Матч за Хельгу подвисал, за монстра — нет. Причин оказалось три, и все три
включались только тогда, когда игрок брал человека, потому что тогда в матче
появлялся **бот-злодей**, которого при игре за монстра просто нет.

1. **Лог ошибок на шестьдесят строк в секунду.** Бот-лич каждый кадр спрашивал
   `get_meta("tether_target", null)`. В Godot `null` по умолчанию — это не
   «верни null», а «умолчания нет»: движок печатал ошибку. Каждый кадр, всю
   погоню, с записью в файл лога.
2. **Боты думали шестьдесят раз в секунду.** Решение «на кого смотреть, куда
   идти, кого бояться» стоит обхода всего зала с лучами «вижу или нет». Хуже
   всех был вампир: на каждого кандидата в жертвы он пересчитывал всех
   свидетелей — сотни лучей в одном кадре. Теперь боты думают двенадцать раз в
   секунду и вразнобой, а идут по пути по-прежнему каждый кадр, так что
   походка осталась гладкой. Реакция бота — восемьдесят миллисекунд вместо
   шестнадцати, всё ещё быстрее человеческой.
3. **`Game.living()` строила новый массив на каждый запрос**, а запрашивали её
   все и по нескольку раз за кадр. Тридцать актёров превращались в сотню
   массивов. Теперь список пересобирается раз в кадр, а ответ «вижу или нет»
   живёт четверть секунды.

Замер на клубе, тот же матч, headless: было 7.4 мс на кадр в среднем и
1900 лучей в секунду, стало 5.1 мс и около сотни лучей. Худший кадр упал с
16 до 9 мс.

### И почему дёргалось у всех — на каждом укусе

Это оказалось отдельной и более грубой причиной. `set_appearance` пересобирал
тело целиком — сносил узел и инстанцировал модель заново, — а зовётся он на
каждом укусе (вампир показывает истинную форму), на каждом вскрытии чесноком
и когда вскрытие спадает. То есть FBX на семь-пятнадцать мегабайт со скелетом
на семьдесят костей перезагружался **дважды за укус**, в самый неподходящий
момент.

При этом для персонажей со своей моделью «истинная форма» не меняет ничего:
`monstrous` читает только сборщик тел из примитивов, а клыки и бледность
показывает мимика. Теперь тело пересобирается, только если сменилась сама
модель. Счётчик пересборок выведен в отчёт `--perf`: за тридцать секунд матча
их ровно 28 — по одной на персонажа при спавне, и ни одной по ходу игры.

### Качество картинки

Три ступени (`F1`), выбор запоминается в `user://settings.cfg`. Плюс
**самопонижение**: если средний кадр несколько секунд подряд не укладывается
в 33 мс, игра сама снимает ступень и говорит об этом. Обратно не поднимает —
иначе на границе получаются качели. Это единственный честный ответ на
«виснет» без доступа к железу: объёмный туман, экранные отражения и
сглаживание стоят почти всю картинку и почти ничего не добавляют к тому, что
в игре важно, — видеть силуэт и понимать, где ты.

## Как устроено

```
scripts/
  data.gd          автозагрузка Data — персонажи, оружие, все числа баланса, ввод
  game.gd          автозагрузка Game — ростер, таймер ночи, условия победы, тревоги
  world.gd         локации: клуб, верфь, усадьба — геометрия кодом и навмеш
  actor.gd         один персонаж на все роли: движение, урон, голод, психоз, обращение
  player_brain.gd  управление игроком и камера от первого лица
  body.gd          запасное тело из примитивов, если модели нет
  rig_anim.gd      анимация скелета кодом: походка, удар, укус, смерть
  weapon_mesh.gd   серп, шпага, гарпунное ружьё, топор и нож — геометрией
  damage.gd        повреждения по частям тела, кровотечение, последствия
  dialogue.gd      как вампир заговаривает жертву и зовёт в гримёрку
  fx.gd            брызги крови и лужи на полу
  lamp.gd          прожектор, который включают люди
  door.gd          дверь: человек запирает, нечисть выбивает
  sfx.gd           звук: всё синтезируется в память, файлов нет
  quality.gd       три ступени картинки и самопонижение на слабой машине
  cutscene.gd      облёт зала, камера казни, финал
  face_rig.gd      мимика накладкой поверх головы
  prof.gd          секундомер по системам для --perf
  garlic.gd        летящий чеснок и что он делает при попадании
  ai/bot_brain.gd  общее для ботов: путь по навмешу, память, подозрения
  ai/guest_brain.gd    толпа: слоняется, сбивается в кружки, паникует
  ai/human_brain.gd    человек-бот: жжёт жаровни, кидает чеснок, убегает
  ai/vampire_brain.gd  выбор жертвы по числу свидетелей, зов, кормление, отход
  ai/lich_brain.gd     погоня, удар, берсерк
  ai/undead_brain.gd   обращённые: просто идут и бьют
  ui/ui.gd         меню, выбор персонажа, HUD, итог — всё собирается кодом
  main.gd          вход: собирает мир, расставляет ростер, ведёт матч
```

Сцена ровно одна — `scenes/main.tscn`, и в ней один узел со скриптом. Всё
остальное строится кодом: так проект открывается в любой версии редактора и
не ломается на конфликтах в `.tscn`.

Ключевое решение в `actor.gd`: **личность и облик — разные поля**. `char_id`
это кто ты на самом деле (числа, оружие, роль), `appearance_id` — кем тебя
видят. Вампир меняет второе, не трогая первое, и вся механика чужого лица
сводится к одной строчке.

## Проверка без редактора

Матч можно прогнать из командной строки — движок сам играет за всех и печатает,
что происходит:

```bash
godot --headless --path maskarad -- --autotest --allbots --speed=6 --seconds=140
godot --headless --path maskarad -- --autotest --char=moira --seconds=60
```

Флаги: `--char=<id>` за кого играть (пустой — все боты), `--allbots`,
`--speed=N` во сколько раз быстрее реального времени, `--seconds=N` предел
прогона, `--shot=путь.png --shotat=N` снимок экрана на N-й секунде (нужен
настоящий рендер, не `--headless`), `--pitch=N` наклон взгляда для снимка.

Отдельные проверки — каждая появилась после того, как что-то незаметно
сломалось и обнаружилось глазами, а не тестом:

| | |
|---|---|
| `--inputcheck` | что реально лежит в InputMap: действие легко «привязать» и оставить пустым |
| `--modelcheck` | СОБРАННЫЙ рост всех четырнадцати моделей, через настоящий `Actor`: первая версия печатала *нужный* масштаб, и Медея прошла проверку, продолжая ходить куклой |
| `--combattest` | удар в упор и урон по зонам: голова, нога, скорость, руки |
| `--animtest` | проходит ли удар весь путь замах → проводка → возврат, сколько прошла кисть, встают ли обе позы укуса |
| `--weaponcheck --shot=` | стенд с оружием при свете: в тёмном клубе геометрию не разглядеть |
| `--posecheck --shot=` | нечисть с оружием в руках на середине проводки — как клинок лежит в ладони |
| `--handstest` | нажимает настоящие ЛКМ и `E` и говорит, где потерялось нажатие: на уровне ввода, у игрока или в самом действии. Все три поломки выглядят снаружи одинаково — ничего не происходит |
| `--map=<club\|wharf\|manor>` | на какой карте прогонять |
| `--systest` | новые правила боя разом: скорости, запрет драки вскрытому вампиру, сбивание с ног, добивание, линь гарпуна, окно шпаги, состав города |
| `--looktest` | мышь по четырём сторонам: куда поворачивается камера и куда сам персонаж; потеря захвата и возврат; оглядывание на кнопке. Нужен настоящий рендер: без окна мышь не захватывается и проверка молча ничего не измеряет |
