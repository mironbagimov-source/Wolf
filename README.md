# Wolf → «Рейвенсторп — Паразит»

Хоррор-шутер от первого лица в духе **F.E.A.R.** Отряд из трёх наёмников —
**Джейкоб** (вы), **Мойра** и **Томас** — прибывает в норвежское поселение
**Рейвенсторп**, где бесследно исчезли двадцать женщин и десять мужчин. След
ведёт в закрытый исследовательский центр, где ставили опыты и вывели
**паразита**, превращающего людей в гигантских пауков.

Ключевая сцена: у дверей центра отряд встречают **три гигантских паука**; после
зачистки выходит **больная женщина** — говорит про опыты, **бросается на
Томаса**, получает пулю, и **из её тела рождается паук**. Дальше — осада и
прорыв к эвакуации.

## Две играбельные реализации

| Версия | Где | Статус |
|---|---|---|
| **Godot 4** (основная) | [`godot/`](godot/) | Полный вертикальный срез: ганплей, рефлексы (slow-mo), пауки, отряд, скриптовая сцена, волны, звук. Открой `godot/project.godot` в Godot 4.2+ и нажми Play. См. [`godot/README.md`](godot/README.md). |
| **Браузер** (Three.js) | [`web-prototype/`](web-prototype/) | Та же боевая петля одним самодостаточным файлом. Собери `node build.js` и открой `web-prototype/index.html` — играется сразу, без движка. |

Обе версии написаны так, чтобы жить в git как чистый текст (Godot строит мир
кодом; браузерная вклеивает three.js и модель в один HTML), потому что среда
разработки headless — без редактора Godot и без Unity Editor.

## Управление (обе версии)

**WASD** — движение · **Мышь** — осмотр · **ЛКМ** — огонь · **ПКМ** — рефлексы
(замедление времени) · **R** — перезарядка · **Shift** — бег · **F** — фонарь ·
**ESC** — курсор.

Рефлексы замедляют весь мир, но темп стрельбы остаётся реальным — фирменное
преимущество F.E.A.R.

## Браузерный прототип — сборка

```
cd web-prototype
node build.js      # вклеивает vendor/three.min.js + модель в index.html
```
Редактируй `index.template.html`, потом пересобирай. `index.html` — то, что
открывается в браузере (zero внешних запросов, работает и как Artifact).

## Godot — запуск

```
Godot 4.2+  →  Import  →  godot/project.godot  →  Play (F5)
```
Проект полностью процедурный, без бинарных ассетов. Подробности, разбор сцены и
архитектуры — в [`godot/README.md`](godot/README.md).
