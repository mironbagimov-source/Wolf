# Маскарад — готовые сборки

Здесь только собранная игра. Исходники — в ветке
[`claude/vampire-game-ppbgbt`](https://github.com/mironbagimov-source/Wolf/tree/claude/vampire-game-ppbgbt/maskarad),
эта ветка отдельная и пустая нарочно, чтобы бинарники не лежали в истории кода.

## Скачать

| | |
|---|---|
| **Windows** | [Maskarad-Windows.zip](https://github.com/mironbagimov-source/Wolf/raw/build/Maskarad-Windows.zip) — 52 МБ |
| **Linux** | [Maskarad-Linux.zip](https://github.com/mironbagimov-source/Wolf/raw/build/Maskarad-Linux.zip) — 46 МБ |

Распаковать и запустить `Maskarad.exe`. Godot ставить не нужно — движок
внутри файла. Windows покажет «SmartScreen»: файл без подписи, нужно
**Подробнее → Выполнить в любом случае**.

На Linux: `chmod +x Maskarad.x86_64 && ./Maskarad.x86_64`

Правила и управление — в [ИГРОКУ.txt](ИГРОКУ.txt), он же лежит внутри архива.
