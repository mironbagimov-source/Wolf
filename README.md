# Wolf

Асимметричный экшен-хоррор на троих во вселенной киберпанка: **жертвы** vs
**кибер-психи** vs **наёмники**. Ночной корпоративный квартал, ближний бой,
метательные ножи и стелс. Дизайн — см. `docs/GDD.md`.

Стороны сопоставлены с прежним прототипом (внутренние ключи в коде не менялись):
жертвы = `survivor` (Outlast-хоррор, побег), кибер-психи = `cannibal`
(реверсивный хоррор, Альфа = вожак), наёмники = `killer` (Ready or Not: стелс +
ближний бой + ножи).

Этот репозиторий пишется без доступа к самому Unity Editor (headless-среда),
поэтому в нём только код (C#), а не бинарные/YAML-файлы Unity (сцены,
ProjectSettings, .meta). Их нужно сгенерировать локально один раз — дальше
всё синхронизируется через git как обычно.

## Установка (один раз)

1. **Unity Hub** → установить **Unity 2022 LTS** (любая последняя патч-версия
   2022.3.x). Именно LTS — стабильнее для WebGL.
2. При установке движка отметь модуль **WebGL Build Support**.
3. Создай новый проект: **3D (URP)** template. Название не важно, но проще
   всего создать его прямо в клоне этого репозитория, в корне (там, где
   лежит этот README) — тогда `Assets/_Project` из репозитория окажется
   внутри проекта автоматически.
   - Если Unity создаёт проект в отдельной папке — просто скопируй содержимое
     `Assets/_Project` из репозитория в `Assets/_Project` нового проекта.
4. Открой **Window → Package Manager**:
   - Установи **Photon PUN2** (Photon → Photon Unity Networking) — либо через
     Asset Store (бесплатный пакет "PUN 2 - FREE"), либо через Photon сайт.
     Нужен для мультиплеерного режима. Для одиночной игры против ботов Photon
     не обязателен — код это учитывает (см. `INetworkService`).
5. Открой проект, подожди импорт — Unity сам досоздаст `.meta`-файлы для
   всех скриптов из репозитория, это нормально, коммить их вместе с кодом.
6. В `Assets/_Project/Editor` лежит скрипт автосборки тестовой сцены:
   **Tools → Wolf → Build Bootstrap Scene** — создаёт минимальную сцену с
   `GameManager` и точками спавна, чтобы сразу можно было нажать Play.

## Структура

```
Assets/_Project/
  Scripts/
    Core/          — GameManager, состояния матча, настройки баланса
    Networking/    — абстракция над сетью (Offline / Photon)
    Player/        — базовый контроллер + Survivor/Cannibal/Killer
    AI/            — простые боты для режима без сети
    Objectives/    — генераторы, алтарь жертвоприношения, цель-Вожак
    Health/        — здоровье и урон
    UI/            — лобби, HUD
    Utils/
  Editor/          — редакторские утилиты (сборка сцен)
docs/
  GDD.md           — гейм-дизайн
```

## Режимы (переключаются в лобби)

- **BotMatch** — играешь один, остальные стороны — AI. Работает без Photon.
- **Multiplayer** — через Photon PUN2 (нужен App Id, см. ниже).
- **LocalSplitscreen** — несколько локальных игроков (задел на будущее,
  базовая архитектура уже это учитывает через `PlayerControllerBase`).

### Настройка Photon (когда дойдём до мультиплеера)

1. Зарегистрируй бесплатный аккаунт на photonengine.com, создай приложение
   типа **PUN**, скопируй App Id.
2. Вставь его в `PhotonServerSettings` (появится после импорта пакета PUN2)
   через `Window → Photon Unity Networking → Highlight Server Settings`.
3. WebGL-билд с Photon работает из коробки — отдельного своего сервера не
   нужно.

## WebGL-билд

`File → Build Settings → WebGL → Switch Platform → Build`. Для первого теста
скорости хватит; когда дойдём до финального билда — обсудим сжатие
(Brotli/Gzip) и хостинг (itch.io и подобные принимают zip с WebGL-билдом
напрямую).

## Статус

Ранняя стадия: архитектура и скелет систем. Браузерный прототип уже играется
во всех трёх ролях (см. ниже). Конкретная блокаут-карта квартала, арт,
анимации, звук в Unity — следующие шаги.

## Браузерный прототип (web-prototype/)

Параллельно с Unity-проектом — самодостаточная HTML-страница с той же боевой
петлёй от первого лица на Three.js: три стороны (жертва/кибер-псих/наёмник),
выбор персонажа, взлом узлов, имплант-стол, метательные ножи, присед и удар
в спину. Существует потому, что в этой среде нет доступа к Unity Editor, а
браузерную версию можно собирать и тестировать самому.

Управление: мышь — осмотр · WASD — движение · Shift — бег · C — присед ·
ЛКМ — атака/захват · ПКМ — блок/захват · Q — метнуть нож · E — взаимодействие ·
F — фонарь.

- `web-prototype/index.template.html` — исходник (редактировать этот файл)
- `web-prototype/build.js` — склеивает three.js + GLTFLoader + персонажа
  (vendored `vendor/Soldier.glb`, MIT-лицензия из репозитория three.js) в
  один файл без внешних запросов
- `web-prototype/index.html` — собранный результат (`node build.js`), это
  и есть то, что открывается в браузере

После правки `index.template.html` пересобери: `cd web-prototype && node build.js`.
