# Блендеровский пайплайн Wolf

Здесь лежит всё, что игра НЕ строит примитивами в рантайме: импланты и
анимационные клипы. Blender работает headless, как python-модуль — окно и
ручная правка не нужны, вся геометрия описана кодом и пересобирается одной
командой.

## Установка

```bash
python3 -m pip install --target=.bpy bpy      # ~1 ГБ, нужен Python 3.11
```

Каталог `.bpy/` в гите игнорируется.

## Сборка

```bash
PYTHONPATH=.bpy python3 tools/blender/implants.py   # → godot/assets/implants/*.glb
PYTHONPATH=.bpy python3 tools/blender/anims.py      # → godot/assets/anims/wolf_clips.glb
```

Обе сборки ДЕТЕРМИНИРОВАННЫ: шум свой, с фиксированным сидом, поэтому
повторный запуск даёт тот же файл и не мусорит в диффе.

## Что где

| файл | что делает |
|---|---|
| `wolflib.py` | общая кухня: шум, примитивы со скруглением, развёртка, экспорт |
| `implants.py` | 10 начинок для тел + 4 боевых импланта наёмника |
| `anims.py` | клипы ключевыми позами на риге Mixamo |

## Как геометрия соединяется с текстурами

Blender НЕ пишет текстуры. Материал в GLB — это пустой ярлык (`imp_steel`,
`imp_meat`, `imp_gut`, `imp_bone`, `imp_pcb`, `imp_gel`, `imp_frost`,
`imp_char`, `imp_glow`), а настоящий материал с процедурными картами
подставляет игра: `WolfLevel.imp_material()` по имени ярлыка. Так меши
остаются лёгкими (1.2 МБ на все 14 сборок), а текстуры не таскаются в
репозитории.

Развёртку делает `box_uv` — проекция по кубу. Умная развёртка не нужна:
текстуры тайлятся, важна только ровная плотность текселя. **Без UV
процедурные текстуры не ложатся вообще** — материалы имплантов раньше
использовали мировой triplanar, и на детали в 5–15 см из текстуры
вырезался однотонный клочок.

## Система координат

В `implants.py` координаты пишутся как `v(x, вверх, наружу)` — по-годотовски,
где «наружу» это из груди. Перевод в оси Blender и дальше в оси Godot (glTF
переворачивает Y/Z) спрятан внутри `v()`.

Риг в `anims.py` — родной Mixamo: вверх +Y, влево +X, вперёд +Z,
сантиметры. Повороты задаются В ОСЯХ АРМАТУРЫ и переводятся в локальные оси
кости: угадывать локальную ось каждой из 52 костей бессмысленно.

## Куда это попадает в игре

- Начинки грузит `_wound_contents` (main.gd) в полость раны.
- Боевые импланты — `_build_implant_visual` (char_body.gd).
- Клипы ретаргетит `scene_baker.gd` на каждое тело; они ВЫТЕСНЯЮТ одноимённые
  клипы кузницы (`anim_forge.gd`), которая делает их доворотом плюс синусоида.

После пересборки ассетов нужно перепечь сцены персонажей:

```bash
godot --path godot --headless --script res://tools/scene_baker.gd
```
