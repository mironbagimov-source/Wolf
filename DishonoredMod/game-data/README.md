# game-data

Сюда `tools/harvest.py` кладёт данные, снятые с установленной игры:

```
config/              копии ini из папки Config — эталон для сборки режимов
config-catalog.json  каталог секций и ключей, по нему проверяются режимы
manifest.json        список .upk и параметры экзешника
```

## Содержимое этой папки не коммитится

Всё, кроме этого README, перечислено в `.gitignore`, и это не техническая
мелочь, а осознанное правило.

Файлы в `config/` написаны Arkane. Каталог и манифест из них выведены. Это
**содержимое игры**, а не работа авторов мода, и в репозиторий оно не попадает
ни целиком, ни частями.

Работает это так: каждый, кто участвует в разработке, запускает `harvest.py` на
своей легально купленной копии и получает эти данные локально. Репозиторий
хранит только то, что написано нами — инструменты и описания режимов.

Описание режима ссылается на секции и ключи по именам и задаёт свои значения:
имена — функциональные идентификаторы, значения — наш выбор. Скопированный
целиком `Player.ini` — уже файл Arkane. Разница именно здесь.

По той же причине сюда никогда не попадут `.upk` и декомпилированный
UnrealScript. Когда дойдёт очередь до правок пакетов, в репозитории будут
лежать патчи — смещение и новые байты, — а не исходники игры.

Пустая папка — нормальное состояние до первого запуска `harvest.py`.
