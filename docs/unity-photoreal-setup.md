# Unity: фотореал-графика (HDRP) и модели персонажей

Всё тяжёлое уже в коде — сцена, материалы, свет и постобработка строятся
Editor-скриптами за один клик. Здесь шаги запуска и как добавить настоящие
модели персонажей.

## 1. Требования

- **Unity 2022.3 LTS или новее** (Unity 6 тоже подходит).
- Пакет **High Definition RP (HDRP)** — фотореал-пайплайн Unity: физический
  свет, объёмный туман, SSR-отражения, ACES-тонмаппинг.

Код проекта собирается и **без** HDRP (asmdef сам включает HDRP-ветки
дефайном `WOLF_HDRP`, когда пакет установлен) — но картинка «дождь и неон»
включается именно с HDRP.

## 2. Установка (один раз)

1. Открой папку репозитория в Unity Hub, дождись импорта.
2. **Window → Package Manager → Unity Registry → High Definition RP → Install.**
3. Когда пакет доедет, появится **HDRP Wizard** (или открой сам:
   Window → Rendering → HDRP Wizard) → нажми **Fix All**. Согласись создать
   HDRP-ассеты, дождись рекомпиляции.
4. **Tools → Wolf → Build Everything.** Это сгенерирует:
   - процедурные PBR-текстуры и материалы (мокрый асфальт с лужами, бетон,
     металл, неоновые эмиссивы) — `Assets/_Project/Art/Generated/`;
   - префабы (включая нож `ThrowingKnife` — уже привязан к наёмнику, и
     манекены с кибер-обвесом на ботах);
   - сцену **Lobby** и фотореал-сцену квартала **TourBase** (объёмный туман,
     блум, авто-экспозиция, градиентное ночное небо, 3 reflection probe,
     горящие бочки с мерцанием, неоновые вывески со спотами).
5. Открой `Assets/_Project/Scenes/Lobby.unity` → **Play**.

Перестроить только сцену: **Tools → Wolf → Build Night District (Photoreal)**.
Только материалы: **Tools → Wolf → Photoreal → Regenerate Textures + Materials**.

## 3. Модели персонажей — как получить «как в Cyberpunk 2077»

Сразу честно: **ассеты из самой Cyberpunk 2077 использовать нельзя** — это
собственность CD Projekt RED, их нельзя выдирать из игры и класть в свой
проект (ни в коммерческий, ни в бесплатный). Легальный путь — модели «в
стилистике»:

### Автоподхват моделей (уже в коде)

Компонент `CharacterModelSlot` на каждом боте ищет префаб по пути
`Resources/CharacterModels/<Имя>` и, если находит, **сам подменяет манекен**
на модель — без правки сцены. Имена:

| Файл префаба | Кому |
|---|---|
| `Survivor.prefab` | Жертвы |
| `Cannibal.prefab` | Кибер-психи |
| `CannibalLeader.prefab` | Альфа (иначе возьмёт Cannibal и увеличит) |
| `Killer.prefab` | Наёмники |

Путь: создай папки `Assets/_Project/Resources/CharacterModels/` и складывай
префабы туда.

### Где брать модели легально

1. **Mixamo (mixamo.com, бесплатно)** — самый быстрый способ получить
   «нормальные разнообразные» модели: десятки риггованных персонажей
   (киберпанк-типажи там тоже есть: SWAT, панки, зомби-типы под психов).
   - Скачай персонажа: формат **FBX for Unity**, T-pose (или с анимацией).
   - Перетащи FBX в проект, в импорте Rig → Animation Type → **Humanoid**.
   - Из модели сделай префаб c нужным именем в `Resources/CharacterModels/`.
2. **Sketchfab** — фильтр лицензии **CC0 / CC-BY**, поиск «cyberpunk character».
   CC-BY требует указать автора (добавь в README).
3. **Unity Asset Store** — паки «cyberpunk character», у многих есть
   бесплатные версии; лицензия стора разрешает использование в игре.
4. **Poly Haven (polyhaven.com, CC0)** — фотограмметрия для окружения:
   PBR-текстуры улиц/бетона и пропсы. Замени процедурные материалы на их
   карты в `Assets/_Project/Art/` для максимального фотореализма.

> Почему модели не лежат уже в репозитории: сетевая политика окружения, где
> собирается проект, блокирует CDN ассетов — скачать их отсюда физически
> нельзя. Поэтому код готов к моделям, а сами файлы добавляешь ты у себя.

### Анимации

Манекены статичны (скользят). Модель из Mixamo со скелетом Humanoid можно
оживить Animator-ом: скачай с Mixamo анимации Idle/Walk/Run (без Skin),
собери Animator Controller с blend tree по скорости — подключается на префаб
модели; контроллеры игры трогать не нужно.

## 4. Тюнинг картинки

- **Постобработка/туман/небо:** ассет `Assets/_Project/Art/Generated/NightVolume.asset`
  (Volume-профиль): Fog (плотность = Mean Free Path), Bloom, Exposure
  (лимиты авто-экспозиции), Gradient Sky, Vignette.
- **Лужи на асфальте:** `PhotorealForge.cs` → генерация `T_Asphalt_Mask`
  (порог `SmoothStep(0.62, 0.72, ...)` — ниже порог = больше луж).
- **Неон:** материалы `M_Neon*` (яркость в нитах задаётся в `EmissiveMaterial`).
- Если отражения неона в лужах не видны: в HDRP Asset включи
  **Screen Space Reflection** (Lighting → Reflections) — в Volume он
  добавляется автоматически, но фича должна быть включена и в ассете пайплайна.

## 5. Известные ограничения

- Собрано «вслепую» (без Unity в среде разработки) — если после импорта в
  Console есть ошибки компиляции, пришли текст, поправлю.
- Манекены не анимированы — реальная походка появится с риггованной моделью
  (см. §3). Игрок от первого лица своё тело не видит (это норма для FPS).
- Наёмники-боты пока только в веб-прототипе; в Unity BotMatch психи и жертвы
  (перенос `KillerBotBrain` — следующий шаг).
