# Настройка в Unity Editor — киберпанк-ре-тема

Код механик уже в репозитории (`Assets/_Project/Scripts`). Но часть вещей
нельзя сделать без самого редактора — их нужно собрать руками один раз. Этот
файл проведёт по шагам.

> Все пути в меню — для **Unity 2022 LTS** (как в README). Имена полей ниже
> точно совпадают с кодом — их видно в Inspector под соответствующими
> заголовками (Header).

---

## 0. Перед началом

1. Открой проект в Unity Hub (или `File → Open Project` на папке репозитория).
2. Дождись импорта. Unity сам создаст `.meta`-файлы для новых скриптов
   (`FactionInfo.cs`, `CharacterArchetype.cs`, `ThrowingKnife.cs` и др.) —
   это нормально, **закоммить их вместе с кодом**.
3. Открой **Window → General → Console**. Убедись, что нет красных ошибок
   компиляции. Если есть — скинь мне текст, поправлю (я писал без компилятора).

Управление игрока (из `HardwareInputProvider.cs`) — пригодится для теста:

| Действие | Клавиша |
|---|---|
| Движение | WASD / стрелки |
| Осмотр | мышь |
| Бег | Left Shift |
| **Присед** | **Left Ctrl** |
| Атака | ЛКМ (Fire1) |
| Блок (наёмник) | ПКМ (Fire2), удерживать |
| Захват (псих) | G |
| **Метнуть нож (наёмник)** | **Q** |
| Взаимодействие | E |
| Фонарь (жертва) | F |

> Примечание: в браузерном прототипе присед на `C`, а в Unity — на `Left Ctrl`
> (так уже было в проекте). Если хочешь `C` — поменяй в
> `HardwareInputProvider.Crouch` на `KeyCode.C`.

## 1. Префаб метательного ножа (обязательно для бросков)

Без назначенного префаба бросок ножа просто пишет предупреждение в Console и
ничего не кидает. Собираем префаб:

1. В сцене: **GameObject → Create Empty**. Назови `ThrowingKnife`.
2. Выдели его, в Inspector: **Add Component → Throwing Knife**
   (это скрипт `ThrowingKnife.cs`). Поле `Spin Speed` можно оставить `1080`.
3. Добавь визуал-лезвие как дочерний объект:
   - **GameObject → 3D Object → Cube** (создастся в корне — перетащи его
     внутрь `ThrowingKnife` в Hierarchy, чтобы стал дочерним).
   - Задай Transform лезвию: `Scale = (0.03, 0.03, 0.4)`, `Position = (0,0,0)`.
     Ключевой момент — **лезвие вытянуто по оси Z (forward)**: нож летит вдоль
     своего `forward`, так что длинная сторона должна смотреть в +Z.
   - **Удали Box Collider** с этого куба (нож сам делает Raycast — свой коллайдер
     ему мешает). В Inspector кубика: на `Box Collider` → правый клик → Remove
     Component.
4. (Опционально, для неона) сделай материал: **Assets → Create → Material**,
   назови `KnifeNeon`, поставь `Emission` галку, цвет `#00E5FF` (циан),
   перетащи материал на лезвие.
5. Преврати в префаб: перетащи объект `ThrowingKnife` из **Hierarchy** в папку
   **Project** (например `Assets/_Project/Prefabs/` — создай, если нет). Появится
   `ThrowingKnife.prefab`. После этого удали экземпляр из сцены (он больше не
   нужен) и **закоммить `.prefab`**.

> Ножу НЕ нужны Rigidbody и коллайдер — он самодвижущийся и сам ищет попадания
> лучом. Цели (игроки) уже имеют коллайдер (`CharacterController`), так что нож
> в них попадёт. По своей фракции нож не бьёт, владельца не задевает.

## 2. Наёмник: подключить нож и проверить настройки

1. Найди префаб человека-наёмника, который назначен на
   `MatchBootstrapper.killerHumanPrefab` (в сцене геймплея, на объекте с
   `MatchBootstrapper`). Открой его на редактирование (двойной клик по префабу).
2. На компоненте **Killer Controller** заполни заголовок **Throwing knives**:
   - `Knife Prefab` → перетащи `ThrowingKnife.prefab` из шага 1. **(главное)**
   - `Starting Knives` = `3` (базовый запас; архетип «Клинок» добавит +2).
   - `Throw Cooldown` = `0.55`, `Knife Damage` = `75`, `Knife Speed` = `26`,
     `Knife Range` = `24` — можно тюнить.
3. Заголовок **Stealth takedown**:
   - `Backstab Half Angle` = `60` (задний конус в градусах, куда засчитывается
     удар в спину).
   - `Leader Backstab Multiplier` = `2.4` (по Альфе бонус вместо ваншота).
4. Убедись, что у наёмника назначен `Camera Pivot` (заголовок **Look** в
   `PlayerControllerBase`) — из него летит нож и бьёт атака. Обычно это уже так,
   раз работает осмотр мышью.

## 3. HUD: строка стойки / ножей (опционально)

`HUDController` получил новое **опциональное** поле `Stance Text`. Если его не
назначить — просто не будет показываться, ошибок не будет.

1. Найди объект с `HUDController` (на Canvas в сцене геймплея).
2. Создай текст: правый клик на Canvas → **UI → Legacy → Text** (компонент
   `UnityEngine.UI.Text`, тот же тип, что у остальных полей HUD). Помести в угол.
3. Перетащи его в поле `Stance Text` на `HUDController`.
4. Готово: там появится строка вида `Клинок  ·  Ножи 5  ·  присед`.

> `Health Text` и `Generator Text` уже показывают «Здоровье N/N» и «Узлы N/N» —
> ничего дополнительно делать не нужно, тексты уже перекрашены в коде.

## 4. Лобби: кнопка выбора персонажа (опционально)

Выбор персонажа управляется кодом (`CharacterRoster` + `PlayerSelection`), в
редакторе достаточно повесить одну кнопку-переключатель.

1. Найди объект с `LobbyUI`.
2. Создай кнопку: правый клик на Canvas → **UI → Legacy → Button**. Подпиши её,
   например, «Персонаж ▸».
3. Перетащи кнопку в новое поле `Character Button` на `LobbyUI`.
4. Убедись, что назначено `Status Text` — там теперь строка вида
   `Режим: BotMatch   Сторона: Наёмник   Персонаж: Клинок`.

Каждое нажатие кнопки перебирает персонажей выбранной стороны по кругу. Смена
стороны сбрасывает выбор на первого персонажа.

## 5. Как работает выбор персонажа (справка)

Персонажи заданы в коде — редакторских ассетов для них не нужно:
`Assets/_Project/Scripts/Core/CharacterArchetype.cs`, класс `CharacterRoster`.

По 2 архетипа на сторону (статы — множители к базе префаба):

| Сторона | Персонаж | Особенность |
|---|---|---|
| Жертва | Курьер | скорость +12%, HP −15% |
| Жертва | Медтех | скорость −5%, HP +25% |
| Кибер-псих | Мясник | HP +15%, урон +15%, скорость −8% |
| Кибер-псих | Богомол | скорость +12%, HP −15% |
| Наёмник | Клинок | скорость +10%, HP −15%, +2 ножа |
| Наёмник | Броня | скорость −10%, HP +25%, крепче блок |

Множители применяются к локальному игроку в момент спавна (метод
`ApplyArchetype` в контроллерах). Боты играют на базовых статах префаба.
Чтобы добавить/поменять персонажа — правь массивы в `CharacterRoster`.

## 6. Быстрый тест (BotMatch)

1. Открой сцену геймплея (та, где `MatchBootstrapper` — по умолчанию в лобби
   `gameplaySceneName = "TourBase"`; переименуй сцену/поле под свой квартал,
   если нужно).
2. Проверь, что у `MatchBootstrapper` назначены префабы (`...HumanPrefab`,
   `...BotPrefab`) и в сцене расставлены `SpawnPoint` с нужным `faction`.
3. В лобби выбери **Наёмник**, при желании перещёлкни персонажа, жми старт.
4. В матче:
   - **Q** — бросок ножа (следи за счётчиком «Ножи N» в HUD).
   - Подойди к психу **со спины** и **ЛКМ** — должно быть мгновенное убийство
     обычного психа (по Альфе — сильный, но не смертельный удар).
   - Присядь (**Left Ctrl**) и подкрадись — психи должны замечать позже, чем
     когда бежишь (**Left Shift**).
