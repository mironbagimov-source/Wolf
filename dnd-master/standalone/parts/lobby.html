Мастер подземелий

D&D 5-й редакции в чате. Мастера ведёт Claude, правила считает движок, кубики бросает сама страница — и каждый бросок видно всем за столом. Ничего не устанавливается: всё, что нужно для игры, лежит внутри этого файла.

Ключ к мастеру

Мастера ведёт Claude, и обращается к нему сама эта страница. Нужен ключ Anthropic API — он хранится только в этом браузере и уходит только на api.anthropic.com. Взять ключ: console.anthropic.com → API keys.

Правила и справочник — SRD 5.1 (CC BY 4.0, Wizards of the Coast). Карты страница рисует сама. Кампания сохраняется в этом браузере; чтобы перенести её на другой компьютер, выгрузите её файлом из настроек стола.
