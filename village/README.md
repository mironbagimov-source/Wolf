# Волчий Лог

Одиночный сурвайвал-хоррор от первого лица в браузере — в духе Resident Evil
Village, но на славянской нечисти: упыри, вурдалаки, стрыга и графиня-вампир
в усадьбе на холме.

Открывается двойным кликом по `index.html` — без сервера, без сборки, без
единого внешнего запроса. Три с половиной мегабайта одним файлом.

## Что уже играется

Полная глава: деревня → крипта → мельница → ворота → усадьба → босс → финал.
Минут на двадцать, если не умирать.

- **Стрельба с зонами попадания.** Хитскан-лучи, голова считается отдельно
  (наган ×2.8), пули перекрываются стенами. Упырь ловит выстрел в голову и
  валится — окно, чтобы перезарядиться или убежать.
- **Кейс как в RE.** Сетка 6×5, у каждой вещи свой размер, обрез занимает три
  клетки и поворачивается. Место — ресурс: с полным кейсом лут остаётся лежать.
- **Крафт.** Трава + трава = отвар, порох + гильзы = патроны, порох + свинец =
  заряды к обрезу. Патроны почти не покупаются — их собирают.
- **Торговец Ворон.** Купля, продажа хабара, три ветки улучшений на каждый
  ствол, расширение кейса.
- **Нечисть с ИИ.** Слышит шаги и выстрелы, теряет след, обходит препятствия,
  замахивается с телеграфом. Стрыга бьёт на расстоянии и горит от святой воды.
- **Босс.** Пули её не берут — кроме секунды, когда она вскидывается для удара
  и под рёбрами открывается сердце. Три фазы, призыв прислуги, рывок.
- **Сохранения.** У лампады, в `localStorage`. Подобранное остаётся подобранным,
  убитое — убитым.
- **Звук целиком синтезируется** в WebAudio: выстрелы — формованный шум, рычание —
  расстроенные пилы через фильтр, ветер, сердцебиение на низком здоровье.

## Управление

| | |
|---|---|
| `W` `A` `S` `D` | идти, `Shift` — бежать |
| `ЛКМ` / `ПКМ` | огонь / прицел |
| `Space` | блок (тратит выносливость) |
| `R` | перезарядка |
| `1` `2` `3`, колесо | нож / наган / обрез |
| `Q` | метнуть святую воду |
| `H` | выпить отвар |
| `E` | действие |
| `Tab` | кейс |
| `Esc` | отпустить мышь, ещё раз — пауза |

Первый клик по экрану забирает мышь (Pointer Lock). Если браузер его не даёт —
песочница, iframe, запрет — обзор автоматически переключается на управление
смещением курсора от центра, играть можно и так.

## Сборка

Исходники лежат в `src/`, собранный `index.html` коммитится в репозиторий.

```bash
node build.js
```

Скрипт склеивает `src/*.js` (по порядку имён) с `index.template.html` и
вшивает three.js r128, GLTFLoader, SkeletonUtils и `Soldier.glb` — всё это
берётся из соседнего `web-prototype/`, чтобы три мегабайта бинарника не лежали
в репозитории дважды.

**Правь `src/` и `index.template.html`, не `index.html`** — он перезаписывается.

## Как устроено

```
src/
  01-config.js     таблицы баланса: оружие, предметы, рецепты, нечисть, лавка, записки
  02-util.js       математика, AABB-коллизии, лучи (rayBox / rayCapsule)
  03-audio.js      синтез всех звуков, эмбиент, музыкальный слой, сердцебиение
  04-input.js      клавиатура, мышь, Pointer Lock и запасной режим обзора
  05-inventory.js  модель сетки: размеры, поворот, стеки, крафт (без DOM)
  06-gfx.js        рендер, процедурные текстуры, пропсы, персонажи, частицы
  07-zones.js      четыре локации: геометрия, лут, двери, спавны нечисти
  08-player.js     движение, стрельба, перезарядка, блок, урон, вьюмодели
  09-enemies.js    восприятие, состояния, обход препятствий, смерть и лут
  10-boss.js       Морана: фазы, слабое место, рывок, призыв
  11-ui.js         HUD, кейс, лавка, записки, кодовый замок
  12-game.js       состояние, загрузка зон, взаимодействие, сохранения, цикл
```

Всё в одной области видимости — модули просто склеиваются, никаких `import`.
Порядок файлов задаётся именами.

Мир целиком состоит из AABB-коробок: по ним же ходят ноги, летят пули и
проверяется, видит ли упырь игрока. Одна структура на три задачи — поэтому
здесь нет ни навмеша, ни физдвижка.

### Добавить своё

- **Предмет** — строка в `ITEMS` (`01-config.js`). Размер `w`/`h` в клетках,
  `stack`, `kind` определяет, что с ним можно делать.
- **Рецепт** — строка в `RECIPES`. Рецепт вида «сам с собой» (трава + трава)
  подхватывается кнопкой в кейсе автоматически.
- **Тварь** — запись в `ENEMIES` плюс `spawnEnemy('тип', x, z)`. Состояния и
  восприятие общие, отличаются только числа.
- **Локацию** — запись в `ZONES` (`07-zones.js`): `build(W)` рисует геометрию
  хелперами `room` / `house` / `bx`, а `W.interact(...)` вешает всё, к чему
  можно подойти и нажать `E`.

## Чего пока нет

Нет вертикальности (лестниц и этажей), нет расчленёнки, нет анимаций удара у
нечисти — замах читается по позе и звуку. Персонажи стоят на риге `Soldier` из
примеров three.js, перекрашенном и ссутуленном; это заглушка, а не финальный арт.
