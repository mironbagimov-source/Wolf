# CLAUDE.md

Память проекта для будущих сессий Claude Code. Коротко: что это, как запускать,
как проверять, где что лежит и на чём тут легко споткнуться.

## Что это

**Считалка** — асимметричный хоррор 4-против-1 в духе Dead by Daylight на
каркасе «Десяти негритят». Четверо выживших в мёртвых руинах против одного из
трёх убийц (Трикстер / Ведьма / Весёлый Роджер). Основная версия — **Godot 4.5**
в папке `godot/`. Есть браузерный прототип (`web-prototype/`, отстал от Godot) и
ранний Unity-порт (`Assets/`, справочный).

Дизайн целиком — `docs/GDD.md`.

## Рабочий цикл (важнее всего)

Всё проверяется без редактора. Команды запускать **из `/home/user/Wolf`**, не из
`godot/` (иначе `--path godot` не находит проект — частая ошибка).

```bash
# импорт (регистрирует class_name; нужен после правок скриптов)
godot --headless --path godot --import

# логика: headless-прогон матча, ~78 проверок. Ненулевой код = что-то сломано.
godot --headless --path godot --fixed-fps 60 tests/smoke_test.tscn

# картинка: рендер кадров по зонам/добиваниям (Vulkan тут нет → OpenGL3)
xvfb-run -a godot --path godot tests/shot.tscn
# кадры пишутся в scratchpad, смотреть их через Read (png)

# готовый билд Windows: build/windows/Считалка.exe + Считалка.pck
godot --headless --path godot --export-release "Windows"
```

**Правило: любое изменение логики — прогнать `smoke_test.tscn` до зелёного перед
сборкой.** Тесты ставят `is_player=false` и `brain=null` на актёров, иначе
`fill_player_intent()` затирает сценарий пустым вводом.

Рендер тут только `llvmpipe` (софт, без Vulkan) — картинку смотреть через
`xvfb-run` с OpenGL3.

## Рендер = gl_compatibility (не трогать без причины)

`project.godot` → `rendering_method="gl_compatibility"` намеренно. Forward+/Vulkan
есть не на всякой видеокарте, и на такой игра открывалась **чёрным экраном**.
Компат-режим тянут все. Цена — нет SSAO/SSIL (они только Forward+); свет, туман,
свечение, карты нормалей, toon-шейдинг и контуры работают и здесь.

## Ключевые системы и файлы (`godot/scripts/`)

- `world_data.gd` — мир как данные: 5 зон (у каждой `danger`, свет/солнце/небо/
  туман), ~670 стен, проёмы, крюки, щиты, спавны. Всё словарями.
- `nav_grid.gd` — своя сетка путей (волна по метровым клеткам). Не
  NavigationServer3D: поросль Ведьмы проходима убийце и нет — гостю (два графа).
  Бейк растеризует стены в сетку (быстро на 670 стенах).
- `kits.gd` — **весь баланс**: гости+черты, три убийцы, добивания, аномалия
  (бессмертие/импланты/зоны), магазин, считалка.
- `actor.gd` — общее тело: движение по `Intent`, взгляд (мышь + стрелки),
  фонарь игрока, toon-материалы через `sync_materials`.
- `guest.gd` / `killer.gd` — стороны. Убийца — три набора в одном теле.
- `guest_brain.gd` / `killer_brain.gd` — боты (слух, погоня, патруль по зонам).
- `finisher.gd` — добивание: постановка в 4–5 тактов, вживляет имплант.
- `match_runner.gd` — матч: постройка мира, зоны, квест, добивания, развязка.
- `body_skin.gd` / `surfaces.gd` — материалы: процедурные текстуры + карты
  нормалей + toon + чёрный контур (инвертированная оболочка через `next_pass`).
- `ui.gd` — меню, магазин, HUD, финал. `main.gd` — склейка.

Модели: `assets/cast.glb` — 4 тела на одном скелете, слеплены
`tools/blender_cast.py` (риг донорский, Soldier из three.js, MIT).

## Механика аномалии (текущая вселенная)

- **Бессмертие.** Добивание не убивает — вырубает (`State.UNCONSCIOUS`) и
  вживляет имплант (бомба / паразит / истончитель кожи). Сам очнётся через ~20с
  с эффектом импланта; свой может вырезать заранее (чисто). Убийца побеждает,
  уложив **всех разом**; гости — если один ушёл в пролом.
- **Зоны попадания.** У выжившего есть бронированный сектор (урон ×0) и открытая
  кожа (×2). Считается по углу убийца↔тело в `guest.zone_mul()`.
- **Магазин.** Перед матчем, обе стороны, на монеты. `Kits.SHOP` → mods в `gear`
  игрока (`guest.gear` / `killer.gear`).

## Конвенции

- GDScript ловит «Cannot infer type» на `:=` от нетипизированных возвратов —
  ставить явный тип (`var x: float = ...`).
- Мир и баланс — данными, не кодом. Способности читают те же массивы, что и
  столкновения/сетка/рендер.
- Русские комментарии, плотные, по делу — держать стиль.
- `class_name Skin` занят движком → у нас `BodySkin`.

## Доставка билда (наболевшее)

Чат режет файлы >30 МБ, exe игры ~96 МБ → только ссылкой, а Windows/браузер
блокируют неподписанный exe. Что работает:

- **Игровой exe (export template)** сам падает на OpenGL3 при отсутствии Vulkan
  и рисует. Раньше его резал антивирус; отдавать когда защита снята.
- **Подписанный редактор Godot** (с godotengine.org) запускает игру, если рядом
  лежит `Считалка.pck` с тем же именем — но **игнорирует** gl_compatibility и
  упирается в Vulkan (чёрный экран). Поэтому предпочтителен игровой exe.
- Менять в чате достаточно `.pck` (3–4 МБ) — exe у игрока уже есть.
- Готовые сборки лежат в `build/` (в т.ч. `build/Считалка-ИГРА.zip`).
