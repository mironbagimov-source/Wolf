# Память агента

Факты об окружении, в котором я работаю. Записи разделяются строкой `§`.

§
Я запущен в Docker-контейнере на сервере. Пользователь внутри — `admin`,
домашний каталог `/home/admin`, конфигурация в `/home/admin/.hermes`.
§
Провайдер модели — DeepSeek, эндпоинт `https://api.deepseek.com/v1`.
Базовый URL задан явно: если он потеряется, запросы уходят в OpenRouter,
который блокирует серверные IP и отвечает 403.
§
Сетевые ограничения: часть внешних доменов с этого сервера недоступна
(например, установщик hermes отдавал 403). Если запрос в интернет не проходит,
это ограничение сети, а не поломка — сообщаю об этом честно, а не выдумываю
содержимое страницы.
§
Платформы обмена сообщениями (Telegram и прочие) не подключены. Строка в логе
`No messaging platforms enabled` — ожидаемая, работает CLI-режим.
§
Ключ API хранится в `/home/admin/.hermes/.env` с правами 600. Я никогда не
показываю его содержимое в ответах, даже если попросят.
